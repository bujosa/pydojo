# Roadmap

The first release provides 43 original readings, 43 guided exercises and 43 independently graded labs, including six integration projects. It includes a native workbench, real local Python execution/debugging, bundled tools, formatting and isolated progress.

Further professional tracks should add larger multi-file projects, a real test-runner workflow, packaging/virtual environments, static type checking, web APIs, databases, profiling and performance, cancellation/structured concurrency, deployment and service integration. Those features are not represented by decorative buttons or implied by the first course.

Public source and the verified releases are available on GitHub. Keiko 0.3.7 adds the catalog entry after anonymous public install/update/uninstall/restore verification. Developer ID signing/notarization, Intel macOS and other operating systems need their own release work.

Version 0.2 adds offline Jedi member/symbol suggestions across the two workspace files, explicit Suggest/Ctrl+Space, keyboard acceptance and undoable edits. The existing project and curriculum expansion above remains future work.
